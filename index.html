Invasive Ductal Carcinoma (IDC) CNN Classifier

A custom lightweight CNN trained on 277524 histopathological patches from 279 patients' whole-mount slides to detect invasive ductal carcinoma (IDC) in breast tissue. The custom-designed architecture is geared to low-resolution 50×50 patches. Evaluation keeps the clinical context in view, with threshold analysis and probability calibration.

Result: Test AUC-ROC = 0.9518 and AUC-PR = 0.8322 on a patient-level split. At a threshold (0.3294) chosen to prioritise sensitivity, recall is 0.96 at the cost of precision being 0.51.

IDC Grad-CAM Explainer

A research demo that extends the IDC CNN classifier with an explanation layer. The trained CNN classifies a histopathology patch and Grad-CAM overlays a heatmap showing which regions drove the prediction. Gemini then explains the result in plain language and answers follow-up questions in a conversational interface. The explanations are limited to what the model can actually see. The Grad-CAM works on a 6×6 grid over a 50×50 patch, so the assistant describes tissue-level patterns and declines to make cellular or diagnostic claims.

Result: Stress-tested with questions it shouldn't answer (cellular detail, diagnosis, training-data claims).

RAG clinical Q&A assistant

Built a RAG pipeline from scratch without a high-level framework (like LangChain), implementing custom text chunking, page-aware metadata tracking, and an adaptive rate-limiter for resilient large-scale document ingestion. Ingestion is also resumable, so after an interruption or an API rate limit it picks up where it left off instead of starting over.

Result: Each answer is generated from passages retrieved from the source literature, so responses can be traced back to the documents rather than relying on the model's general knowledge.
